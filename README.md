# One in 20,000 raindrops 简体中文双语补丁

《二万分の一の雨粒達》Windows Steam 版非官方汉化补丁，包含第三轮校对文本、日文对照、秋水書体字体与原有字体设置功能。需要正版游戏本体，不能独立运行。

## 下载

前往 [Releases](https://github.com/chankamman-dev/OneIn20000Raindrops-CN-Patch/releases)，下载 `OneIn20000Raindrops-CN-Patch-v0.3.0.zip`，不要把自动生成的 Source code 压缩包当作补丁。

当前为预发布：实际启动、双语显示及字体设置的运行检查尚未完成，不代表已通过完整流程测试。

## 安装

1. 完全退出游戏，在 Steam 中右键游戏 → 管理 → 浏览本地文件。
2. 将游戏目录的 `resources/app` 完整备份到游戏目录之外，并另行备份存档。
3. 解压补丁，将其中的 `resources` 文件夹复制到游戏根目录，合并并覆盖同名文件。不要替换整个游戏目录。
4. 启动后检查对话、双语和字体设置；异常时退出并恢复备份。

不要与其他汉化混装；其他游戏版本的兼容性尚未确认。补丁不含游戏程序、图片、音频、存档、备份或校对工作簿。游戏自身运行时可能更新存档和设置。

## 回退

关闭游戏，恢复安装前的 `resources/app` 备份。新增文件只按安装前后清单对照移除，不要直接删除整个 `resources` 或 `app`。Steam 验证完整性不一定清除额外文件，也不会恢复其他模组，优先使用自己的备份。
